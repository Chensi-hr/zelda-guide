1. 余料建造是怎么运作的

按住 L 打开素材轮盘，选一个素材融合到当前武器 / 盾 / 箭上。融合会继承素材的属性与伤害，并覆盖原武器的"元素 / 特性"。武器会坏，但融合素材可以临时续命并改属性，是王国之泪战斗的核心乐趣。

2. 融合素材推荐

  • 岩石 / 金属块：最廉价的钝击加成，前期随手捡随手融。
  • 兽角（如莫力布林角、莱尼尔角）：锐利加成，伤害显著；白银莱尼尔角是顶配。
  • 冰冷鲤 / 火蜥蜴 / 电气鱼：给武器附加冰 / 火 / 雷属性，克制对应敌人。
  • 僵尸左手（Zombie Arm）：不错的伤害加成，地下常见。
  • 盾融合尖刺 / 螺丝：让盾能主动刺击，近身反打更强。
  • 箭融合：蝙蝠眼（自动追踪）、史莱姆冻（元素）、噗噗菇（烟雾弹）各有奇效。
小技巧：融合素材的"基础伤害"会直接加进武器；想堆极限伤害，就用高攻素材 + 高攻底武器组合。

3. 防具套装

  • 海利亚套装：初始防具，均衡好用。
  • 卓拉 / 鼓隆 / 利特 / 格鲁德套装：分别对应抗水游泳、抗火、抗寒、抗热 / 抗沙，是该地区的"门票"。
  • 幻影套装：三件集齐攻击力提升，输出流标配。
  • 古代兵装（Ancient Hero's Aspect）：单件集大成的强力防具。
  • 潜行 / 攀登 / 滑翔套装：功能性极强，按需获取。

4. 升级与妖精

防具可在各地的大妖精之泉（Great Fairy）升级，提升防御并解锁套装效果（同套装穿满特定件数触发）。升级需要怪物素材与噗哟宝石（Bubbul Gem）——后者来自呀哈哈屋主（把克洛格种子交给森林里的克洛格即可获得）。

循环建议：收集呀哈哈 → 换噗哟宝石 → 解锁大妖精 → 升级核心套装，是一条清晰的成长主线。
