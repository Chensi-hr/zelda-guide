1. 普通敌人

  • 波克布林（Bokoblin）：最常见杂兵。背后与头部是破绽，可盾反、可偷袭。
  • 蜥蜴战士（Lizalfos）：灵活爱闪避，注意它的横扫与跳劈。
  • 构装体（Construct）：与"究极手 / 余料建造"同源的机械敌人，弱点是发光核心，打掉核心会瘫痪。
  • 莫力布林 / 莱尼尔（Moblin / Lynel）：精英级，高伤高血，建议用属性克制与林克时间。
  • 幻影加农（Phantom）：地下世界常见，动作与加农相似，留意外形闪烁的破绽。

2. 四大神殿 BOSS（Regional Phenomena）

  • 利特村 · Colgera（冰龙）：空中单位，多用弓箭与远程，借上升气流接近，打掉身上的冰晶后输出本体。
  • 鼓隆火山 · Marbled Gohma（魔像蜘蛛）：攻击它的腿与单眼，破防后核心暴露，趁机猛攻。
  • 卓拉领地 · Mucktorok（污泥怪）：先清理它喷出的污泥限制走位，再用水属性 / 普通输出。
  • 格鲁德 · Queen Gibdo（沙后）：先清掉周围亡灵小兵，再集中打它核心，注意沙暴干扰视野。

3. 最终决战：Ganondorf（魔王）

集齐四位贤者后进入海拉鲁城堡，与魔王 Ganondorf 决战。战斗分多阶段，会引入 gloom（瘴气）机制——踩到瘴气会持续掉血并临时扣上限，记得用光明花 / 抗瘴料理处理。贤者会帮你吸引火力，善用地图标记规划进攻路线，并准备充足的回血与属性武器。

战前清单：武器 / 防具尽量升级，备足回血料理与抗瘴手段，带上火 / 雷属性武器应对不同阶段。

4. 通用打法建议

  • 盾反（Shield Parry）：在敌人攻击命中前一刻按 A，反弹并制造硬直，对强敌极有效。
  • 林克时间：完美闪避或射箭时触发慢动作，集火输出。
  • 属性克制：火克冰、冰克雷等，针对敌人弱点上属性武器。
  • 余料建造加伤：用高攻素材融合，普通武器也能打出爆发。
