1. 烹饪机制

在锅边打开背包，选食材丢进锅里烹饪，就会得到料理。料理效果由食材组合决定：

  • 生命恢复：肉 / 鱼 / 蔬果类，回血心心；加"生命"类食材可回上限（黄心）。
  • 攻击 up / 防御 up：加入怪物素材（角、爪等）触发，叠加越多等级越高。
  • 耐寒 / 耐热：对应冷暖食材（如暖暖草抗寒、清凉花抗热）。
  • 移动速度 / 潜行 / 电击 / 火 / 冰抗：由特定食材决定。
  • 同名食材叠加：同一种效果食材越多，buff 越强、持续时间越长。
小技巧：龙素材（龙角 / 龙鳞）做出的料理有极长时效性的增益，是毕业级储备。

2. 核心配方（示例）

  • 大份烤肉：5 块兽肉 → 大量回血，最基础的续命料理。
  • 攻击增益：兽肉 + 怪物角（如莫力布林角）→ 攻击 up，打 BOSS 前吃。
  • 耐寒料理：暖暖草 / 暖暖蘑菇 → 抵御海布拉的严寒。
  • 耐热料理：清凉草 / 西瓜 → 扛住格鲁德的高温。
  • 速速料理：速速胡萝卜 → 移动速度 up，赶路 / 逃命用。
  • 潜行料理：潜行蘑菇 / 静悄鱼 → 潜行 up，偷袭与拍照友好。

3. 关键食材

  • 龙素材（Dragon Parts）：四神龙掉落的角 / 鳞 / 爪，长效增益核心。
  • 怪物素材：角、爪、肝脏等，提供攻击 / 防御加成。
  • 噗噗菇（Puffshroom）：做烟雾弹料理，脱战神器。
  • 各类花草：对应抗性或 buff，沿区域气候分布。
